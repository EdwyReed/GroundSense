# GroundSense executable prototype — shared development contract

All new runtime files stay in this repository. Existing research, contracts and accepted PNGs remain intact. UI is Ukrainian. Civil industrial workflow, synthetic geometries only; no operational routes/coordinates in conflict areas. Implement real interactions/persistence, not screenshots as UI. Never invent field validation, permissions to drive or live provider health.

## Ownership

- Web worker: ONLY `apps/web/**` (Vue3/TS/Vite/MapLibre/ECharts, npm dependencies/lock). No backend/infra edits.
- API worker: ONLY `apps/api/**`, `requirements-runtime.txt`, `tests/runtime_api/**`. Backend FastAPI/SQLAlchemy, tests and persisted operations. No web/science/infra edits.
- Parent: `packages/**`, `runtime/**`, `infra/**`, scripts, integration QA and hosting; shared contract changes coordinated.

## Runtime

Frontend built to apps/web/dist. FastAPI serves it at /; all JSON under /api/v1. Vite proxy /api -> http://127.0.0.1:12110. Backend import `apps.api.main:app`, run project root. Database env GROUNDSENSE_DATABASE_URL (SQLAlchemy; postgres+psycopg in deployment, SQLite fallback for tests). Storage dir env GROUNDSENSE_DATA_DIR. Parent provisions .venv and infrastructure. Runtime requirements include fastapi, uvicorn, sqlalchemy, psycopg[binary], httpx, python-multipart, jsonschema[format-nongpl], rfc8785, Pillow, reportlab, pytest. Do not run shared service restarts.

## Sessions and authority

Public prototype defaults to isolated synthetic sandbox, not a shared writable global database. GET bootstrap creates a strong random HttpOnly SameSite=Lax session cookie and scoped sandbox workspace. Server derives workspace and role from session, never accepts tenant/workspace authority from JSON. CSRF returned bootstrap; every mutation requires X-CSRF-Token and exact same Origin; missing Origin is403 even for nonbrowser clients (tests send the configured Origin explicitly). Sandbox roles may be demonstrated via explicit /demo/role ONLY for that session's synthetic workspace; cannot create global admin privileges or external network side effects. Demo role defaults engineer. Anonymous sandbox is explicitly labelled; do not claim OIDC is configured. Production/private OIDC is a separate configurable boundary and never silently bypassed. Persistent per-session data and opaque IDs; prohibit cross-session ID reads/writes. Tests cover these. Never expose internal locators, DB credentials or OAuth tokens.

## Bootstrap and endpoints (wire surface for this prototype)

GET /api/v1/bootstrap returns {workspace,context,user:{role,display_name,permissions},csrf_token,assets,segments,sources,observations,inspections,protocols,models,envelopes,constraints,tickets,subscriptions,notifications,runs,soil,map,features,capabilities}. All arrays may be empty after edits but errors are never represented as successful empty data. features = original70-row feature map with honest runtime implementation status/evidence, not a fake completeness percentage.

POST /api/v1/demo/role {role:dispatcher|engineer|field|admin} -> new user role (same sandbox only).

GET /api/v1/{resource} and POST /api/v1/{resource}, PATCH /api/v1/{resource}/{id} for assets,segments,observations,inspections,protocols,models,envelopes,constraints,tickets,subscriptions. Persist and audit every write, versions append rather than overwriting original evidence. DELETE if supported records tombstone. PATCH and admin DELETE require an explicit positive interoperable JSON integer expected_version (at most 9007199254740991). Missing/null/boolean/float/string/zero/negative versions are422; a stale version is409. DELETE accepts JSON {expected_version}, applies the same SQL compare-and-swap as PATCH/adjudication, and atomically appends a versioned tombstone snapshot and audit event. Read-only catalogues cannot be deleted. GET /api/v1/audit returns scoped audit events. POST /observations/{id}/adjudications {decision:accepted|rejected,reason,expected_version} is engineer/admin only; require reason and preserve original.

Models and vehicle envelopes are metadata-only in this sandbox. Writable fields: name, description, scope, card_ref, source_ref, reason (text/null), status (non-null enum), synthetic (boolean/null), and calibrated/model_approval/production_eligible (false/null only); id and expected_version are control fields. Status is draft/research/blocked/withdrawn. Unknown or nested object fields are422, including approval objects. Read views explicitly set metadata_only=true and model_approval/production_eligible=false. Legacy unsupported fields are projected out on reads/exports without rewriting raw history; a legacy claimed calibration becomes unknown, not verified.

POST /api/v1/analyses {assessment_date,gross_mass_t} with Idempotency-Key -> {id,run_id,status,mode,reused,assessment_date,gross_mass_t}; duplicate key+same request reuse, changed payload409. Job state is persisted, cooperative cancel, no publish of cancelled/failed. GET /api/v1/jobs/{id}, POST /api/v1/jobs/{id}/cancel. GET /api/v1/results/{run_id} returns assessment + manifest metadata and dynamic freshness/withdrawal. POST /api/v1/results/{run_id}/withdraw {reason}. GET /api/v1/forecast?asset_id=GS-014&assessment_date=2027-03-15&gross_mass_t=20 returns science `assess` below. Date/mass changes don't alter physics by mass. Source/science status honest. GET /api/v1/results/{id}/manifest returns scoped manifest (RFC8785, sha256 no self digest). Parent science available as `from packages.science.engine import assess`; fallback ONLY explicit unavailable error, not fabricated series.

POST /api/v1/imports {resource,format:csv|geojson|json,data:string} -> {id,status:preview,rows,errors}; explicit POST /imports/{id}/commit dedupes hash and audits. Validate bounds/type/size, no arbitrary URLs. Asset imports expected columns id,name,type,longitude,latitude (demo-only scope); field data not silently trusted. POST /uploads multipart file -> {id,sha256,size,mime,status}; hard size cap, image decode/re-encode/no SVG/HTML, private scoped GET /uploads/{id}. POST /exports {format:csv|geojson|pdf,json scope/run optional} -> {id,download_url,sha256,expires_at}; GET /exports/{id}/download authorized and safe, CSV formula injection escaped, PDF real report (ReportLab) with Ukrainian glyphs. GET /offline-package -> JSON scoped snapshot with digest+expiry; POST /offline-package/restore or UI import never claims fresh status.

POST /sources/{id}/sync is on-demand explicit action. Configured adapters only; parent adds source adapters. No arbitrary user-supplied fetch URL. Missing adapter returns409/explicit unavailable, not green. POST /models/{id}/approve requires report/evidence and actual valid domain; synthetic data cannot approve production domain. POST /validation/evaluate calls parent optional science evaluation; no empty fake metrics. Science experiments POST /science/research are labelled synthetic/research and cannot publish G2. External CMMS/evacuation/ML integration configurations can be saved/tested but absent endpoint/permission/data is visible and blocks effect. Do not use arbitrary-webhook SSRF; no automatic outward notifications in sandbox.

GET /api/v1/health -> {status,storage,version}. Optional parent AI routes `/api/v1/ai/status` and POST `/api/v1/ai/explain` {asset_id,run_id?} same session+CSRF; web must degrade when AI unavailable. Explanation only, no physics or instruction to drive. No API keys in frontend.

## Science response required by web/API

Parent function `assess(assessment_date:str,gross_mass_t:float,asset:dict,seed:dict)->dict` returns {asset_id,assessment_date,gross_mass_t,mode,synthetic:true,model_version,knowledge_cutoff,computed_at,forecast_issue_time,condition,reason_codes,mobility:{kind:'unavailable',risk:null,status:'unknown',reason_codes},series:[{time,moisture_p10,moisture_p50,moisture_p90,precipitation_mm,temperature_c}],recovery:{status,distribution_kind,event_time_convention:'confirmation_end',persistence_hours,horizon_end,probability_by_horizon,p10,p50,p90,cdf,bounds_by_horizon,lost_weight_mass},source_supports,warnings}. Series are actually computed from an explicit synthetic water-card experiment, not represented as measured data. Real forcing-only paths have moisture null/unavailable if science gates fail.
