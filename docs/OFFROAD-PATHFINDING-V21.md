# Off-road pathfinding V21 — implementation checkpoint

Status: candidate search and its map integration are published and exercised in the live application. The user stopped the recurring redesign loop after the bounded final verification. This is not completion of the vehicle-ground/recovery product.

## Product contract

The primary flow remains map → A/B → trip date/vehicle → candidate paths → selected section. Search must inspect a two-dimensional region and actually find a path around excluded cells, rather than call a geodesic transect a route. Keep the existing inspector and map-first desktop/mobile composition; do not add a geotechnical form.

Candidate search and validated vehicle mobility are separate outputs. The initial candidate policy is static and heuristic. Date and mass remain bound to the trip and its contextual evidence, but do not alter the search until an applicable model exists. No passability score, admissible mass, drying/reopening date, tree clearance or current flood inference.

## Implemented area adapter

`apps/api/terrain_grid.py` reads only the existing approved WorldCover 2021 v200 and Copernicus GLO-30 DSM templates. It builds an A/B bounding region with a 500 m search margin. This is a bounded search extent, not exhaustive regional coverage.

- Endpoints: 1 m..20 km apart, latitude −75..75°, no antimeridian crossing. Native area ≤4,000,000 pixels, search grid ≤65,536 cells and ≤512 per axis; ≤4 approved tiles per product. Limits may reject a request even when endpoint distance is within 20 km.
- Native categorical mosaics preserve the source pixel phase. Coarsening uses the most costly native class and excludes a coarse cell if any represented native pixel is unknown or policy-excluded. A one-cell exclusion buffer is retained; narrow native barriers are not replaced by nearest-neighbour land-cover sampling.
- Authored relative costs: tree 1.4, shrub 1.3, grass 1.0, crop 1.2, bare/sparse 1.3, wetland/mangrove 5.0, moss/lichen 1.5. These are planning preferences, not measured vehicle responses. Classes 50/70/80 (mapped built-up/snow-ice/permanent-water) are excluded by this policy, not asserted to be current observations or exact building footprints.
- DSM is sampled on the search grid with native scale/offset and mask handling. Missing/nonfinite DSM excludes a cell. DSM includes vegetation/buildings; relief penalties must not be presented as ground-slope limits for a truck.
- Source evidence binds the native categorical array digest, search cost/DSM array digests, transforms, extent, grid spacing, tile identities, policy and retrieval time. A bounded four-entry/300-second immutable-result cache serializes cold reads.
- A returned cell path must bind to the exact requested endpoints, remain on traversable adjacent cells, and not cut blocked corners. Conversion removes only collinear grid steps, never a line-of-sight shortcut. Geometry ≤256 vertices and ≤20 km; budget failure must not become a straight fallback.
