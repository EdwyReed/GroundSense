# AI в прототипе GroundSense

AI не участвует в физике, оценке проходимости, допуске научной модели и проверке полевых измерений. Для этих задач нужны явные параметры, проверяемые алгоритмы и данные; языковая модель не закрывает пробелы.

Проверено 25.10.2026 через штатный `hermes proxy start --provider nous` на приватном loopback endpoint. `GET /v1/models` реально вернул каталог из 424 записей. В нём есть варианты `:free` с нулевыми `pricing.prompt` и `pricing.completion`, включая `upstage/solar-mini4:free`. Это свидетельство текущих полей каталога, не гарантия политики подписки, квоты или работоспособности inference. Вызовы inference не выполнялись. Сырой публичный каталог сохранён только в ignored runtime/nous-models.json.

Для нынешнего интерфейса модель не нужна: причины отказа и протоколы объясняются детерминированно. Никакой агентный API с памятью, инструментами или доступом к профилю в приложение не подключён. Таким образом, приложение не передаёт в модель координаты, фотографии, наблюдения и частный контекст; публичные посетители не расходуют подписку владельца.

Если появится обоснованная задача языкового разбора, использовать серверный адаптер к штатному приватному subscription proxy, не копировать credentials в приложение. До каждого включения проверять текущие нулевые цены/срок доступности модели, применить общий и per-user лимит, явно разрешить минимальный набор передаваемых данных. Недоступность бесплатного варианта не должна переключать приложение на платную модель.
