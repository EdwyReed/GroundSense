# Исправление: реальные источники под исходным интерфейсом

Требование пользователя: НЕ новая страница и НЕ упрощённый интерфейс. Сохранить исходные App.vue, masthead, querybar с датой/массой, шесть вкладок, боковые панели, inspector, drawer, RegistryForm, таблицы и графики. Менять bindings, содержимое данных, честные подписи и внутренний map source. Не менять style.css, сетку, типографику или дизайн. LiveWorkspace не является основным экраном. Этот контракт отменяет решение о двух интерфейсах из LIVE-DATA-CONTRACT.md.

Первоначальный перечень: inputs/soil_trafficability_chat.md; проверенные детали и ограничения: docs/02-DATA-SOURCES.md. Требуются подключения продуктов Sentinel-1/2, CLMS SWI/SSM, SoilGrids, ERA5-Land, Copernicus DEM, ECMWF IFS/AIFS, DWD ICON, NOAA GFS, OSM; дополнительные исторические/контекстные источники HWSD/ESDAC, CLC/TCD/WorldCover также отражать с реальной доступностью, не выдавать каталог за полученные измерения. Использовать бесплатный/пробный доступ законно; родитель ведёт регистрации в Chrome при необходимости. Ключи только на сервере, никогда в DTO/логах/JS.

## Backend интеграция

`create_app(data_mode: str|None=None)`: по умолчанию public_data, явный synthetic только для сохранения старых тестовых сценариев. Основные URL остаются /api/v1/bootstrap, /forecast, /analyses, /jobs, /results, /asset-context и существующий CRUD/import/export/evidence. Не переносить приложение в отдельный namespace.

В реальном bootstrap НЕ clone_seed. Если текущая browser session относится к старому синтетическому workspace, создать новую scoped session/workspace и перенести только прежние live_assets/live_weather_snapshots (не синтетические записи); не уничтожать старую историю. Использовать marker Resource.kind=workspace_config/id=public-data-v1, не глобальный переход всех пользователей. Существующий validated CRUD, CAS, audit, import/export и evidence сохраняются в обычных kind внутри нового реального workspace. Модели/транспорт остаются metadata-only и не approved. Реальные assets из формы имеют честное synthetic=false, condition=unknown, identity_verified=false; геометрия и источник обязательны, значения по умолчанию не придумывать.

Bootstrap прежней формы: workspace/context/user/csrf_token/все resource arrays/soil/map/features/capabilities. context.assessment_date = текущая UTC-дата, gross_mass_t=20; map.mode=public_data, пустой FeatureCollection без выдуманных геометрий. soil неизвестен до извлечения: composition null, support_m null, depths []; никакого seed. Реестр может быть пустым. Этого недостаточно для завершения задачи без подключения источников.

`GET /api/v1/asset-context?asset_id=...&assessment_date=...` -> `{asset_id,assessment_date,soil,terrain,land_cover,satellites,history,sources,synthetic:false}`. Asset из текущего workspace, фиксированные провайдеры, никакого произвольного URL/SSRF. Sources хранят id/name/product/version/status/qc/note + retrieved_at/observed_at/content_sha256, отсутствующие поля null. Status available только при фактическом чтении соответствующих данных; metadata-only помечать partial. Ошибки отдельных провайдеров partial/unavailable, без synthetic fallback.

`/forecast` и analysis jobs используют реальные model weather data. После добавления [исследовательского расчёта](11-LIVE-RESEARCH-CARD.md) mode=`research_water_balance`, synthetic=false, model_version=`live-warm-water/1`; прежний `series[{time,moisture_p50,moisture_p10:null,moisture_p90:null,precipitation_mm,temperature_c}]` остаётся рядом поставщика для выбранной UTC-даты, не собственным водным балансом. Отдельный `research` содержит трёхсценарный двухслойный баланс до 72 часов, критерий условного подсыхания, все допущения, причины abstention и raw digest. `condition` — исследовательский итог на конец рассчитанного горизонта (unknown при отказе), не измеренное состояние подъезда. `mobility` и дорожный `recovery` остаются unavailable. `input_snapshot` сохраняет точные входные данные и параметры; его digest входит в job manifest. Не запускать synthetic science_assess при public_data и не обходить approved/observed gates прежнего research_run. Jobs/cancel/withdraw/idempotency сохраняются.

## Изолированные модули провайдеров

Общая форма adapter result:
`{id,name,product,status:'available'|'partial'|'unavailable'|'auth_required',qc:'available'|'partial'|'unavailable',note,retrieved_at,observed_at:null|string,content_sha256:null|string,data:object}`. Не возвращать секретные/подписанные URLs. Кэш bounded, raw evidence сохранять отдельно от transient indexes. Рабочая точка для настоящего probe — публичная Осло 59.91,10.75, не промышленный объект/маршрут.

1. `apps/api/static_sources.py`: `StaticSources(cache_dir:Path)`; `read(latitude,longitude)->dict` с ключами soil/terrain/land_cover/sources. soil прежней формы + provenance; SoilGrids реальные sampled raster значения с units/scale/nodata/depth/uncertainty из metadata. Terrain Copernicus GLO-30 DSM, WorldCover class — реальные чтения небольших окон, не полная загрузка глобуса. Разрешено добавить rasterio в runtime через родителя. Ошибки/NoData возвращать unknown без нуля и без выдуманного soil texture.
2. `apps/api/remote_sources.py`: `RemoteSources(cache_dir:Path)`; `read(latitude,longitude,assessment_date:str)->dict` с ключами satellites/history/sources. Sentinel-1/2 и CLMS: фактическое product metadata/discovery; попытаться получить небольшой настоящий asset/pixel через легальные public mirrors, без заявления о завершённой SAR preprocessing при metadata-only. ERA5-Land: получить и сохранить фактический исторический ряд, единицы/глубины. Отразить доступность ECMWF/DWD/GFS/OSM и остальных источников исходных файлов; catalogue listing не считать извлечением raster. Секреты из env только если требуются, не читать/печатать private env-файлы.

Backend owner интегрирует эти два интерфейса в app.state.static_sources / app.state.remote_sources. Оба конструктора без сети; реальные чтения по запросу asset-context, не блокировать bootstrap. Провайдеры работают независимо с явной частичной доступностью, UI показывает источники в существующей таблице. Не менять чужие файлы/не коммитить.
